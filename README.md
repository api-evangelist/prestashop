# PrestaShop

PrestaShop is an open-source e-commerce platform with a REST API for managing products, categories, orders, customers, carriers, stock, and tax rules for online stores.

## APIs

- **Webservice API** - Full CRUD access to 60+ shop resources via HTTP Basic Auth
- **Admin API** - Modern REST API (PrestaShop 9+) with OAuth 2.0 client credentials
